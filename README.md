# 💰 Bank Loan EDA & Analysis (Python + Plotly)

I developed a **Bank Loan Analysis Dashboard** using **Python, Pandas, NumPy, and Plotly** to explore lending performance across multiple borrower profiles and loan attributes.  

The project provides **end-to-end insights** — from loan applications to repayments — enabling **risk assessment, borrower segmentation, and portfolio health monitoring** through interactive data visualization.

## 📊 Key Metrics (KPIs)
- **Total Loan Applications:** 38,576  
- **MTD Loan Applications (Dec 2021):** 4,314  
- **Total Funded Amount:** $435.76M  
- **MTD Funded Amount:** $53.98M  
- **Total Amount Received:** $473.07M  
- **MTD Amount Received:** $58.07M  
- **Average Interest Rate:** 12.05%  
- **Average DTI (Debt-to-Income):** 13.33%  

**Loan Quality Breakdown**  
- ✅ **Good Loan Applications:** 33,243 (86.18%)  
   - Funded: $370.22M  
   - Received: $435.79M  
- ❌ **Bad Loan Applications:** 5,333 (13.82%)  
   - Funded: $65.53M  
   - Received: $37.28M
